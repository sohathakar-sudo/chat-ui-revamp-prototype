# UI consistency audit: Figma vs prototype (17 Nov 2026)

**What was compared:** Figma page "Nov 16" (Iteration 3 and Paper, 15 frames) against the local prototype and the live Vercel site (wysa-chat-revamp.vercel.app), Variant C.

**Vercel vs local:** they run the exact same code (identical build files), so every item below applies to both. On Vercel every image and font loads fine. The only thing that can look different there is the font on non-Apple devices (see D1).

**How to use this list:** work top to bottom.
1. **Part A:** your decisions. Tick a choice for each.
2. **Part B:** straightforward fixes where the prototype is simply off from Figma. No decision needed, just a go-ahead.
3. **Parts C–E:** things for design, and things already confirmed.

Each item has an ID (D1, F1, …) so you can say "do F1–F9".

## Part C — States the app has but Figma doesn't (need design sign-off)

These were built from existing Figma styles, but no designer has seen them:

- **Voice:** Reconnecting (spinner plus message), Connection failed, Microphone denied, Timed out ("Tap to start"), and the four error messages (mic, silence, network, reply). The error screen copy is a stand-in, because Figma's frame only says "Error state".
- **Voice:** the "jump to latest" button, the "Work in progress" note on the menu icon, and the glows that pulse with voice volume.
- **Chat, transcribing:** after you tap Check, a spinner replaces the waveform while the recording is transcribed, and Pause and Check go half-faded.
- **Chat, paused recording:** the bars drop flat and the label changes to "Resume", but the icon stays a pause icon. Design should decide whether it becomes a play icon.
- **Chat:** the error message pops in with no animation.
